# v1.2 资源与适配说明

来源仓库：https://code.kp-para.cn/paracraft/maisi ，提取时commit `24714b66e08c241c20a3f56f6a62bd911a340bc1`。运行时不访问maisiDev或CDN。

逐项来源、字节数及当前SHA256见 `资源清单.json`。共享静态资源的URL取自源仓 `games/resource-manifest.js` 中shared-components记录，7个图标及6段音效已下载本地。未发现项目资源的单独开放授权书；这里是该项目内部复用，不据此主张可公开分发。结算滚分及结束提示音沿用原组件WebAudio合成，不存在遗漏的MP3。

原样提取了介绍页、介绍顶栏、游戏顶栏、session、升级/时间到、结算及其必要样式和音频依赖。为了独立运行作以下适配：

- shared-assets和resource-loader改为本地映射/解码，只登记本模板使用的资源；不加载整仓资源表。
- 结算重玩移除正式平台lifecycle标志调用，改由公共shell控制。
- 结算数字滚动尺寸使用设计坐标而非缩放后的屏幕坐标，避免窄屏显示错数字/截断。
- 升级/时间到的外观仍用原组件；在shell管理的容器中由可暂停生命周期控制显示时长，避免暂停后后台计时继续。
- 顶栏真实高度覆盖为72px、按钮56px；游戏容器1280×728；背景1280×800；整页统一等比缩放。
- 确认预览的✓完成了！/✕再试一次由template实现同一外观。单款反馈持续时间限1–2秒。

示例缺失项：小院散步真实教学动画/MP4、介绍配音、单款教学配音、正式图标和全屏背景未在此公共示例封装。界面明确显示“演示素材待提供”，并提供视频接口；不能把当前占位与已验收视频画等号。第二款案例的缺失项见该案例说明。

公共MP3文件已落盘；实际声音听感仍需使用预览的六个试听按钮确认。浏览器首次用户手势前拒绝自动有声播放时不会伪称播放成功。

`资源清单.json`保留源文件哈希sourceSha256与适配后的sha256，可用根目录verify.py核对锁定版本。模板后续修复后应更新清单；不允许单款游戏悄悄改公共样式。
